# Mission 1 — Understanding Computer Systems

## 1. Task / Objective

The purpose of this mission is to explore the basic functioning of a computer system. It involves understanding the IPOS cycle, distinguishing between hardware and software, and identifying computer-based systems commonly used in everyday activities.

## 2. Work Completed

### Task 1.1 — Trace One Activity Using IPOS

**Chosen activity: Searching for information on the internet.**

IPOS represents Input, Processing, Output and Storage. These stages describe how a computer accepts data, works on it and provides useful results.

| Stage | What happens in this example? | Hardware / Component |
|---|---|---|
| Input | I enter a search query using the keyboard or voice input. | Keyboard / Microphone |
| Processing | The processor handles the input and the browser communicates with the search engine to retrieve relevant results. | CPU and RAM |
| Output | The search results are displayed on the screen. | Display |
| Storage | Browser cache and saved browsing data may be stored for future use. | SSD |

**Explanation:**

When I search for something online, I first enter a query through the keyboard. The computer processes this input and the browser sends a request over the internet. The search engine returns relevant information, which is displayed on the screen. Some browsing information, such as cached data, may also be saved on the computer's storage device.

### Task 1.2 — Identify Hardware and Software

| Item | Classification | Purpose |
|---|---|---|
| Webcam | Hardware | Captures images and videos. |
| Speakers | Hardware | Produce audio output. |
| Microphone | Hardware | Captures voice and other sounds. |

| GPU | Hardware | Processes graphics and visual computations. |
| Cooling Fan | Hardware | Helps prevent computer components from overheating. |

**B. Software**

Software consists of programs that provide instructions to computer hardware.

| Software Name | Classification | Software Type | Purpose |
|---|---|---|---|
| Windows 11 | Software | Operating system software | Manages computer resources and provides a user interface. |
| Google Chrome | Software | Application software | Used to access websites and online services. |

| Windows Defender | Software | Utility software | Helps protect the computer against malware and security threats. |

### Task 1.3 — Computer Systems Around You

| System | Main Purpose | One Input | One Output |
|---|---|---|---|

## 4. My Understanding

This mission helped me understand how a computer performs different operations through the IPOS cycle. Every computer system requires some form of input, processes the received information and generates an output. Storage allows information to be retained for future use.

I also learned that hardware and software depend on each other. Hardware provides the physical resources, while software gives instructions that make those resources useful.

Another important concept I learned is that computers are used in many devices beyond traditional desktops and laptops. Payment terminals, gaming consoles and biometric attendance systems are examples of computing technology used in everyday life.
